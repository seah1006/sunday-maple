# Phase 4 정규화·카테고리 설계 (초안 — 사용자 확정 대기)

> `data/interim/reward_inventory.csv`(고유 보상 113개) 기반. 정규화 입도 = **수치 통합**(2배/3배/5배, %, 개수, 분, 회 등 수치 변형을 하나의 `reward_norm`으로). 강도는 별도 컬럼 `reward_magnitude`로 보존 제안.
> Codex가 적용할 사전의 초안이다. **열린 결정(§4)**을 확정하면 Phase 4 Work Packet으로 확정한다.

## 1. 제안 컬럼 추가

| 컬럼 | 설명 |
|---|---|
| `reward_norm` | 정규화 보상명 (수치 제거, 표기·어순·명칭변화 통합) |
| `reward_magnitude` | 통합으로 사라지는 강도 보존 (예: `2배`, `30%할인`, `250%`, `50개`). 없으면 null |
| `category` | 대분류 (§3) |

## 2. reward_norm 그룹 (수치 통합)

### 강화
- `스타포스_비용할인` ← 스타포스 강화 비용 30% 할인
- `스타포스_성공확률` ← 스타포스 5,10,15성…성공확률 100% / **샤이닝 스타포스 타임**(특별시간 별칭, is_special)
- `스타포스_1+1강화` ← 10성 이하에서…1+1 강화
- `스타포스_파괴방지` ← 21성 이하에서…파괴 확률 30% 감소
- `주문의흔적_비용할인` ← 주문의 흔적 강화 비용 50%/30% 할인
- `흔적복구_비용할인` ← 흔적 복구 비용 20% 할인
- `어빌리티_재설정할인` ← 어빌리티 재설정 비용 50% 할인
- `잠재능력_재설정할인` ← 잠재능력 감정 및 재설정 비용 50% 할인
- `환생의불꽃_지급` ← 강력한/영원한 환생의 불꽃 5개…지급 (월드당 최대10개 변형 포함) ⚠️§4-2

### 성장
- `경험치_배수버프` ← 경험치 2배 / 몬스터 사냥 시 경험치 3배 혜택 / **익스트림 레벨업 타임**(별칭, is_special)
- `경험치쿠폰_지급` ← 경험치 2배·3배 쿠폰 (15/30분) N장 지급 (전부 통합)
- `룬_경험치버프` ← 룬 경험치 버프 효과 +100% / 지속시간 2배
- `룬_재등장감소` ← 룬 재등장 및 재사용 대기시간 감소
- `콤보킬_경험치` ← 콤보킬 경험치 획득량 +300% / 99콤보마다 콤보킬 구슬 추가
- `몬스터파크_경험치` ← 몬스터 파크 클리어 경험치 추가 250%/50% / 성장의 일요일 상자 2배
- `버닝` ← 버닝 필드(단계상승·유지) / 테라·메가 버닝 부스터 지급
- `성장의비약_지급` ← 익스트림/폭풍 성장의 비약 N개 지급
- `유니온_코인` ← 메이플 유니온 일일퀘스트 코인 7배
- `우르스` ← 우르스 일일 입장 2배 / 하루 종일 메소 2배

### 사냥효율
- `현상금_경험치` ← 폴로와 프리토(,에스페시아) 현상금 사냥 경험치 1.5/2/3/5배 (명칭변화+수치 통합)
- `불꽃늑대_경험치` ← 불꽃늑대 퇴장 시 경험치 1.5/2/3/5배
- `엘리트몬스터_증가` ← 사냥 시 소환되는 엘리트 몬스터 수 증가 (1→2, 1→3 포함)
- `솔에르다_사냥` ← 사냥을 통해 획득하는 솔 에르다 2배/3배 / **솔 에르다 타임**(별칭, is_special)
- `트레져헌터_경험치` ← 트레져 헌터 경험치 3배
- `아케인리버_보상` ← 아케인리버 1~6지역 일일 컨텐츠 보상 2배
- `돌발미션` ← 돌발미션 클리어 경험치 2배/3배 / 일일 횟수 2·3·5배 / 더 자주 발생
- `명예의훈장` ← 필드 몬스터 명예의 훈장 명성치 5배
- `보스파티_버프` ← 보스파티 결성 버프 효과 증가
- `파티퀘스트` ← 월드 통합 파티퀘스트 입장 2배 / 파티 포인트 5배
- `심신수련관` ← 심신수련관 입장용 부적 지급
- `엘리트마일리지` ← 엘리트 몬스터 마일리지 꾸러미 횟수 4배

### 수집/기타
- `몬스터컬렉션` ← 신규 몬스터 등록 100% / 의문의 모몽 1·3개 / 탐험 시간 50% 단축
- `위대한소울_확률` ← 소울 조각 사용 시 위대한 소울 5배
- `심볼교환권_지급` ← 선택 아케인심볼 교환권 20/30/50개 / 선택 심볼 1개
- `솔에르다_접속지급` ← 접속 시 솔 에르다 1개 / 접속시간 2분마다 조각 교환권 / 누적접속 보상 ⚠️§4-3
- `VIP부스터_지급` ← 접속 시 VIP 부스터 10개
- `캐릭터슬롯_지급` ← 캐릭터 슬롯 증가 쿠폰
- `데미지스킨_지급` ← 데미지 스킨 선택 지급(샤방 변형 포함)
- `유니온프리셋_지급` ← 메이플 유니온 프리셋 쿠폰 1·2개
- `프리미엄PC방` ← 프리미엄 PC방 접속 시간 2배 누적
- `리부트_드롭률` ← (리부트, 리부트2월드: 하루 종일 드롭률 2배)
- `선물_기타지급` ← 썬데이메이플 선물 / 운영자 특별 선물 / 메생역전 머니상자 / 솜사탕 핑크빈 교환권 / 마스터 라벨 패키지 교환권

### 스페셜(시간 한정 — §4-1 결정에 따라 카테고리 or 플래그)
- `미라클타임` ← 미라클 타임
- `코디타임` ← 레이디 블레어의 코디 타임
- `헤어타임` ← 로드 블레이의 헤어 타임
- `펫타임` ← 쁘띠 펫 타임
- (샤이닝스타포스/솔에르다/익스트림레벨업 타임은 위 해당 benefit norm의 별칭으로 흡수)

## 4. 열린 결정 (사용자 확정 필요)

1. **스페셜을 "카테고리"로 둘까, "플래그(is_special)"로만 둘까?**
   - (A) 스페셜=별도 카테고리: "X 타임" 보상은 category=스페셜. 직관적이나 "샤이닝 스타포스 타임"(=강화) 같은 게 강화에서 빠짐.
   - (B) 스페셜=플래그만: 모든 보상은 benefit 카테고리로, is_special=True만 표시. 카테고리 일관성↑, 스페셜 단독 분석은 플래그로.
2. **환생의 불꽃: 강력한 vs 영원한 통합?** (스타포스 성장단계가 다른 별개 아이템) — 통합 / 분리(`환생의불꽃_강력한`, `_영원한`).
3. **솔 에르다: 사냥 획득 vs 접속 지급 통합?** (획득 방식·성격이 다름) — 분리 권장.
