## 작업 1 — 기존 코드 주석 제거 (발표자료 규칙, 프로젝트 전체)

**배경**: 발표 시 주피터 노트북을 실행하며 진행하므로 코드가 화면에 노출된다. 프로젝트 전체에서 인라인 주석·docstring을 제거한다. Claude가 grep으로 확인한 잔존 주석은 아래 4곳뿐이다(오탐 아님). 색상코드 `'#4C78A8'` 등 문자열 속 `#`은 주석이 아니므로 건드리지 않는다.

**수정 대상 및 정확한 위치**:
- `src/features.py` — 함수 docstring 2개(약 7~12행, 39~44행 `"""..."""`). 삭제하고 함수 본문은 그대로 둔다.
- `src/normalize.py` — 205행 인라인 주석 `# Keep one coarse magnitude token ...`. 주석만 제거(코드 라인이 주석만 있는 줄이면 줄 삭제, 코드 뒤 주석이면 `#` 이하 제거).
- `notebooks/02_parse_clean.ipynb` — cell8의 `# by_type의 명시 주기와 by_date raw 기준 계산 주기를 비교한다. 결과는 저장하지 않고 출력만 한다.` 라인 삭제. 이 설명이 필요하면 같은 위치에 **마크다운 셀**로 옮긴다(코드 주석으로 두지 않는다).

**검증 요구사항**:
- 제거 후 `python -m pytest -q` 34개 통과(docstring·주석 제거로 동작 변화 없음).
- `02_parse_clean.ipynb` 재실행 성공, tidy 1160행·14컬럼·`(date,reward_raw)` 중복 0 불변.
- 제거 후 재확인: `src/` 및 `notebooks/`에서 인라인 주석·docstring이 0인지 grep. (테스트 파일 `tests/`는 발표 화면에 노출되지 않으므로 이번 범위에서 제외 — 이견 있으면 다음 Phase에서 처리.)

## 작업 2 — `outputs/report/final_report.md` 작성

**수정 대상**: `outputs/report/final_report.md`(신규). 그림은 상대경로 `../figures/{name}.png`로 임베드.

다음 구성으로 작성한다. 각 절은 발표 슬라이드 1~2장 분량의 서술 + 근거 수치.

### 1. 프로젝트 개요와 데이터 출처
- 분석 목적: 선데이메이플 정규 보상 등장 패턴을 9년치(2017-03~2026-06) 정형화해 운영 변화와 보상 패턴을 본다.
- 데이터 출처: 인벤 게시글 단일 2차 자료(`data_dictionary.md` 7-1). 원본 불변 원칙.
- 분석 단위: 한 행 = "특정 날짜에 등장한 하나의 보상"(`reward_raw`), 무결성 키 `(date, reward_raw)`.

### 2. 데이터 파이프라인
- 수집(01) → 파싱·정제(02) → 교차검증(03) → EDA(04) → 보조 모델(05) 단계 분리, 중간 산출물 파일 전달.
- tidy 스키마 14컬럼을 표로 요약(`data_dictionary.md` 3장에서 가져옴).
- 핵심 전처리 판단 3~4개를 의사결정 로그(`data_dictionary.md` 8장)에서 골라 근거와 함께 서술: 관측 단위 `reward_raw` 확정, 별칭/분리 정규화(환생불꽃·솔에르다), 미래 빈 블록 유지, `(요일)` 헤더 정정.

### 3. 데이터 신뢰성 검증
- 공식 공지 스팟체크 3회차 결과 표(위 확정 수치). 인벤 원본 = **정규 보상 정확, 이벤트 연동 일회성 보상 제외** 스코프임을 명시(`data_dictionary.md` 7장).
- 내부 교차검증(by_type vs by_date) 일치율 0.726을 보조 근거로.

### 4. 탐색적 분석 (EDA 4종)
각 질문 = 질문 1문장 → 그림 임베드 → 해석 2~3문장. 4개 질문·7개 그림을 모두 사용한다.
- **Q1 카테고리 구성 변화**: `../figures/q1_category_share_by_year.png`. 강화·사냥효율 비중 추세, 2017·2026 부분 연도 주석.
- **Q8 회차당 보상 수**: `../figures/q8_rewards_per_session.png`. 2017 ~2.0 → 2025 ~3.5 증가(운영 강화).
- **Q2 재등장 주기**: `../figures/q2_cycle_by_norm.png`, `../figures/q2_cycle_hist.png`. 주력 보상 짧은 주기 vs 희귀 보상, 중앙값 42일, 최대 2030일 원값 유지 주석.
- **Q3 단종/생존**: `../figures/q3_discontinued_by_category.png`, `../figures/q3_last_seen_year.png`. 카테고리별 단종 편중(사냥효율·성장), 마지막 등장 연도 분포(2018 정리 피크).
  - **단종 해석 주석(사용자 결정)**: 원본 작성자의 `(단종)` 표기를 그대로 "단종"으로 제시하되, **마지막 등장이 2024~2025인 9건(2024=8, 2025=1)은 데이터 시점상 잠정일 수 있다**는 한 줄 주석을 단다.

### 5. 보조 베이스라인 모델
- 목적: 각 보상의 다음 등장 간격을 과거 주기 중앙값으로 예측(보조·최소).

- **보조 목표**임을 명시(CLAUDE.md: 예측 모델 과투자 금지).
