## 3. 발견한 리스크

### 3.1 인벤 원글 갱신 중단 (가장 큼)

- 2026-10-24에 원글을 1회 다시 요청해 확인했다. 제목이 `(~2026.06.07)역대 썬데이메이플 정리`이고, 날짜별 뷰는 06-14 이후 날짜만 있고 보상이 비어 있다. **4개월 넘게 갱신이 없다.**
- 따라서 매주 자동 갱신하려면 새 출처가 필요하다. 06-14 ~ 10-25 사이 약 20회차가 비어 있다.

### 3.2 공식 공지는 이미지

- 공식 썬데이 공지(예: `https://maplestory.nexon.com/News/Event/1405`, 2026-10-25 회차)는 본문 `.new_board_con` 안에 **PNG 한 장**뿐이고 alt 텍스트가 없다. 정정 안내 같은 텍스트가 가끔 붙는 정도다.
- 이미지는 장식 폰트라 일반 OCR(Tesseract)로는 오인식 위험이 크다. 비전 LLM으로 읽으면 정확하지만 API 비용이 생긴다(주 1장이라 아주 적음).
- 공지 탐지는 NEXON Open API의 이벤트 공지 조회(무료, API 키 필요)나 이벤트 목록 페이지로 할 수 있다. Open API를 쓰면 데이터를 30일 안에 갱신해야 하고, 출처 표기가 필요하다.

### 3.3 신규 보상

- (정정) 10-25 회차의 `[HEXA 스탯] 메인 스탯 강화 확률 20% 증가`는 이미 `HEXA스탯_강화확률`(2024-07-21 최초, 8회)로 사전에 있다. 다만 공식 공지 문구는 인벤 표기와 다를 수 있고(예: `트레저 헌터 경험치 3배`) 신규 보상도 생길 수 있으니, 수집 단계에서 미등록 보상을 감지하고 사람이 사전에 추가하는 흐름은 필요하다.

### 6.3 비용

- 공지 이미지 1장 ≈ 수천 토큰. 소형 비전 모델 입력가는 100만 토큰당 약 $0.10(Claude Haiku 5.5, GPT-6 Luna, 2026-10 기준). 주 1장이면 연간 수십 원 수준이고, 백필·검증 30장도 무시할 수준이다. Gemini 일부 모델은 무료 티어가 있다. 최종 선택은 사용자 승인.

### 6.4 참고: 06-21 실제 vs Phase 20 예보

- 06-21(스페셜) 실제: 트레저 헌터 경험치 3배, 룬 재등장·재사용 대기시간 감소, 룬 경험치 버프 +100%, 콤보킬 경험치 +300%, 몬스터파크 클리어 경험치 +250%, 사냥 솔 에르다 2배.
- RF 상위5(몬스터컨렉션, 스타포스_비용할인, 주문의흔적_비용할인, 어빌리티_재설정할인, 엘리트몬스터_증가)는 0개 적중. Prophet 상위5(몬스터파크_경험치, 주문의흔적_비용할인, 룬_경험치버프, 콤보킬_경험치, 스타포스_비용할인)는 3개 적중(눈으로 확인, 정규화 키 매핑은 Phase 23에서 확정). 모델 선택·재학습 정책(§5-2) 논의 재료.
