## 원인 분류와 처리

- (b) 정규화 규칙 부족: 룬 재 등장/몬스터파크 붙여쓰기/트레저 표기/썬데이 메이플 선물/잠재능력 승급확률2배 문구를 기존 키의 추가 별칭으로 처리했다. 기존 tidy 매핑은 불변이다.
- (c) 인벤·공식 범위 차이: 1300과1304의 챌린저스 월드 전용 혜택은 Claude가 이미지를 대조해 확인했다. 인벤에는 해당 전용 혜택이 없어 scope=all만 비교한다. 각각 전용 보상3개가 있다.
- 샤이닝 스타포스 타임은 헤더이지 보상 항목이 아니다. 하위3개 혜택만 추출한다. 일반 제목 공지에 전용 헤더만 있으면 전체 is_special=False 유지, note에 해당 헤더와scope를 보존한다.
- 최초 scope 미구분 프롬프트는10/12 완전일치(정밀도0.896825/재현율1.0). scope_v2 및 추가 별칭 적용 후 결과가 위 표다.

## 백필 사람 리뷰와 예외

백필20회차83개 추출행을 Claude가 직접이미지대조9공지/패턴승인11공지로리뷰했고,선물구성품과미라클세부행을제목행으로병합해78행으로확정했다. 미라클타임은인벤관례상보상제목행이며,샤이닝·솔에르다타임은꼬리표다. 공식CSV의review_method와note가승인근거를보존한다. 룬기본지속시간증가는새키룬_지속시간증가/성장으로승인됐다. 2017년룬경험치버프지속시간2배는기존키를유지한다.

향후추출프롬프트는미라클/선물예외를반영한scope_v3다. 본표12/12는scope_v2실측이고,v3는아직실측하지않았다.
