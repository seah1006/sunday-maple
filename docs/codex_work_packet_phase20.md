## 작업 2 — 06-14 "예측 vs 실제" 표 복원 (셀 11)

현재 display 3개에 더해, **분류기가 예측한 상위 5위를 게이트 전/후로 보여주고 실제 등장 여부를 표시**한다. 예시 구현(주석 없이):

```
def top5_with_actual(table, actual_rewards):
    view = table.head(5)[["순위", "reward_norm", "점수(%)"]].copy()
    view["실제등장"] = view["reward_norm"].isin(actual_rewards).map({True: "O", False: "X"})
    return view.rename(columns={"reward_norm": "예측보상"})

display(pd.DataFrame({"실제_06_14_보상": sorted(actual_0614)}))
display(top5_with_actual(pred_0614_raw, actual_0614))    # 게이트 전 예측 상위5
display(top5_with_actual(pred_0614_gate, actual_0614))   # 게이트 후 예측 상위5
```

- 마크다운(셀 9 또는 인접 위치)에 "게이트 전엔 예측 상위5에 단종 보상이 섞여 실제를 0/2로 놓쳤고, 게이트 후엔 몬스터파크가 5위로 올라와 1/2를 맞혔다. 선물_기타지급은 두 경우 모두 후보권 밖"이라는 해석 한두 줄을 한글로 추가(이미 있으면 보강).
- 기존 display(gate_summary, 실제 보상 순위 표, prophet_0614)는 유지하거나, 위 표와 중복되면 정리해 가독성 우선. 단 06-14 적중수 0/2→1/2와 실제 보상 위치는 어떤 형태로든 보이게 유지.
- 새 표의 수치는 모델 출력에서 나오므로 별도 하드코딩 금지.
