## 작업 1 — 재증 게이트 + 도메인 단종 목록 (`src/predict_dataset.py`)

**수정 대상**: `src/predict_dataset.py` — `build_inference_frame`(및 필요 시 `_candidate_rewards` 보조 함수). 추론 경로에만 게이트를 적용한다(아래 "백테스트 영향" 참조).

**변경 목표**:
- 추론 후보 선정 시 다음 두 필터를 추가한다(기준일 = `target_date`):
  1. **재증 게이트**: 후보의 `target_date` 미만 마지막 eligible 등장일이 `target_date`로부터 `recency_gate_days`(기본 180)일을 초과하면 제외.
  2. **도메인 단종 목록**: 모듈 상수로 `DOMAIN_DISCONTINUED = {"스타포스_1+1강화"}`(사용자 도메인 입력, 데이터 미표기 보강)를 두고 후보에서 제외.
- 두 필터는 파라미터/상수로 노출해 노트북에서 값과 근거를 명시할 수 있게 한다. 기본값으로 동작이 결정적이어야 한다.
- `recency_gate_days`로 후보가 0개가 되는 경우는 발생하지 않지만(활성 보상 다수 존재), 방어 코드는 추가하지 않는다.

**구현 전략**: `_candidate_rewards`가 빈도 top-N을 뽑은 뒤, 후보별 "기준일 미만 마지막 등장"을 계산해 게이트·도메인 목록으로 거른 최종 후보 리스트를 만든다. 빈도 top-N을 거른 뒤 부족분을 다시 채울지(재선정) 여부는 **재선정하지 않음**(상위 빈도 후보 중 살아있는 것만 사용; 단순함 우선). top_n는 기존 20 유지.

**검증 요구사항(`tests/test_predict_dataset.py`)**:
- 게이트 임계값 초과로 특정 보상이 후보에서 빠지는 케이스 1개(예: 마지막 등장 371일 전 보상 → 제외).
- 임계값 이내 보상은 유지되는 케이스 1개.
- `DOMAIN_DISCONTINUED` 보상이 간격과 무관하게 제외되는 케이스 1개.
- 게이트가 `target_date` 미만 이력만 본다는 누수 금지 케이스 1개(target 당일/이후 등장은 "마지막 등장"에 포함하지 않음).

**기존 결과 영향**: `build_inference_frame` 출력 후보 수가 20 → (게이트 적용 후) 줄어든다. 추론표가 바뀐다(현상금·불꽃늑대·스타포스성공확률·스타포스1+1강화 제거).

### 백테스트 영향 (명시적 결정)
- 게이트는 **추론 경로에만** 적용한다. `build_prediction_frame`(백테스트)의 후보 universe는 cutoff=2025-01-01 기준으로 선정되며, 그 시점엔 현상금·불꽃늑대가 아직 활성이었으므로 게이트가 백테스트를 바꾸지 않는다.
- 따라서 **백테스트 비교표 4행 수치는 Phase 14와 동일하게 유지**된다. 노트북·리포트의 백테스트 표는 변경 없음(재실행 시 동일).
- 리포트·노트북 텍스트에 "백테스트는 원시 모델 능력, 전방 예보는 재증·도메인 게이트 적용"의 구분을 한 문장으로 명시한다.
