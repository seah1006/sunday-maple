# Codex Work Packet — Phase 8 (데이터 출처·신뢰성 검증 문서화: 공식 공지 스팟체크)

> 사용자 지적: 원본이 인벤(2차 자료, 일반 유저 작성)이라 공식 자료 대조가 필요. 사용자 결정: **스팟체크 + 한계 문서화**, **EDA 전에 선행**. 본 Phase는 Claude가 직접 수행한 공식 공지 스팟체크 결과를 리포트/노트북에 정형화한다(추가 데이터 수집·코드 로직 변경 없음, 문서·마크다운만).

## 작업 배경 (Claude 직접 조사 — packet에 사실로 확정)

원본 `data/raw/`는 인벤 게시글(`https://www.inven.co.kr/board/maple/2304/20563`, 한 유저가 9년간 정리한 2차 자료) 단일 출처다. 공식 넥슨 공지와 대조 필요성 검토 결과:

1. **공식 공지 형식**: 넥슨 메이플스토리 공식 이벤트 페이지(`maplestory.nexon.com/News/Event/...`)가 썬데이 회차별로 존재하나, **보상 목록이 전부 이미지(PNG/JPG)로만 게시**되어 텍스트 자동 대조는 불가. 구 회차 일부는 접근 제약. → **수동 스팟체크**가 현실적.
2. **Claude 수행 스팟체크**(공식 이미지를 직접 판독해 tidy와 대조):

   | 날짜 | 공식 이벤트 페이지 | 공식 보상 수 | tidy(인벤) 일치 | 결과 |
   |---|---|---|---|---|
   | 2026-04-19 | News/Event/Ongoing/1310 | 3 | 3/3 | 완전 일치 |
   | 2025-07-27 | News/Event/Ongoing/1178 | 4 | 4/4 | 완전 일치 |
   | 2023-05-21 | News/Event/765 | 5 | 3/3(상시분) | **이벤트 전용 2개 미수록** |

   - 2026-04-19 공식 3개(HEXA 스탯 강화확률 20% / 주문의 흔적 50% 할인 / 몬스터파크 250%) = tidy와 동일.
   - 2025-07-27 공식 4개(룬 재등장 감소 / 룬 경험치 +100% / 콤보킬 +300% / 트레져 헌터 3배) = tidy와 동일.
   - 2023-05-21 공식 5개 중 상시 3개(1+1 강화 / 룬 +100% / 콤보킬 +300%)는 tidy와 동일하나, **이벤트(메이플릴 어드벤처) 연동 보상 2개**(`메이플릴 리프·캔디 획득량 2배`, `메이플릴 어드벤처 획득 보상 2배`)는 인벤 원본에 미수록.
3. **누락은 파서 결함 아님 — 인벤 원본의 스코프 선택**: `data/raw/view_by_date.txt`의 2023-05-21 블록에 보상은 상시 3개만 존재(메이플릴 보상 라인 0건, grep 확인). 인벤 작성자가 **상시(정규) 보상만 정리하고 이벤트 연동 일회성 보상은 제외**한 것.
4. **결론**: 인벤 2차 자료는 **정규 썬데이 보상에 대해 정확**(2회차 7/7 완전 일치). 단 **이벤트 연동 일회성 보상은 제외**하는 스코프 한계. 분석 대상이 정규 보상 패턴이므로 신뢰성 확보. 내부 교차검증(by_type↔by_date, 일치율 0.726)이 보조 일관성 근거.
